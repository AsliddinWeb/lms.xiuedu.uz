## Ta'lim rejimlari

| Atama | Tavsif |
|-------|--------|
| **Sinxron rejim** | Real vaqtdagi o'zaro aloqa (live darslar) |
| **Asinxron rejim** | Bir xil bo'lmagan vaqtdagi o'qish (yozib olingan video, vazifalar) |
| **Hibrid (gibrid)** | Aralash — masofadan + an'anaviy |
| **Avtoproktoring** | AI orqali imtihonni avtomatik nazorat qilish |
| **Inson-proktoring** | Jonli kuzatuvchi orqali nazorat |
